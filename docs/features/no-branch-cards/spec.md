# Spec：不建分支的卡片，與工作頁卡片顯示專案名稱

- 狀態：已確認（2026-11-16 使用者：「照 plan 實作」）
- 更新日期：2026-11-16

## 背景

1. 工作頁左側「In Progress」清單的卡片第二行同時放專案名稱與進度 chip，專案名稱被截斷成前半段，分不出卡片屬於哪個 repo。
2. 每張卡開始執行時都會建立分支 `vf-<id>`（或指定名稱）＋ worktree，並在有 remote 時推送。有些任務（查問題、研究、試驗）不需要分支。

## 需求

### A. 工作頁卡片

- 卡片增高一行：第二行**獨立**顯示專案名稱（完整寬度、仍可截斷但不再與 chip 共用一行）。
- 原本第二行的位置改放**分支名稱**＋進度 chip。
- 不建分支的卡片：分支位置顯示「無分支」。master 卡維持顯示「Master」，不加專案行。

### B. 建立卡片時可選「建立分支」

- 新增卡片對話框加一個開關「建立分支」，**預設開啟**。開啟時行為完全不變。
- 關閉時：
  - 專案是 git repo → 開始執行時仍建立**獨立 worktree**，但用 **detached HEAD**（從最新的 base 切出），不建分支、不推送。
  - 專案不是 git repo → 允許建卡；agent 直接在該資料夾執行（沒有 worktree 可建）。
  - 分支名稱欄位隱藏。
- CLI：`task create --no-branch`。
- 建立後不能切換（Backlog 編輯只能改文字、專案、base）。

### 刪除／完成

- detached worktree：完成（Done）或刪除時照常移除 worktree；不刪任何分支（本來就沒有）。worktree 內未推到其他地方的 commit 會變成無法從分支取得（outcome 仍記錄 commit 清單）。
- 非 git 資料夾：完成或刪除時**絕不**刪除或改動該資料夾，也不做 base 同步。

## 驗收條件

- AC-1 工作頁卡片：標題／專案／分支＋chip 三行；長專案名不再與 chip 爭寬度。
- AC-2 對話框預設開啟「建立分支」，建卡結果與現在相同。
- AC-3 關閉後在 git repo 建卡並開始：worktree 存在且 `HEAD` 為 detached，`git branch` 沒有新分支，沒有 push。
- AC-4 關閉後選非 git 資料夾可以建卡；開始後終端機 cwd 是該資料夾；Git diff 分頁顯示為空而不報錯。
- AC-5 非 git 卡完成或刪除後，資料夾內容完全不變。
- AC-6 既有卡片（沒有新欄位）行為不變，不需 migration。

## 不做

- 已建立的卡片切換有／無分支。
- TUI 新增卡片表單的開關（CLI 與 Web UI 有；TUI 之後再補）。
