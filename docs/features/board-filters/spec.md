# Spec：看板篩選（專案、標籤）

- 狀態：草稿（依使用者需求直接實作，決策見下方「假設」）
- 需求來源：使用者需求（2026-11-25）：「在看板區域，需要有一個 filter 可以快速過濾專案、tag，各自欄（Backlog, In Progress, Done）一起套用」
- 更新日期：2026-11-25

## 問題與目標

看板頂列原本只有單選的「專案」篩選，無法同時看兩個專案，也無法依標籤（卡片在等什麼）過濾。

目標：看板頂列提供「專案」「標籤」兩個複選篩選，一次套用到 Backlog、In Progress、Done 三欄。

## 行為

- 專案、標籤都是複選；同一篩選內為 OR，兩個篩選之間為 AND。沒勾任何值 = 該篩選不作用。
- 專案選項：看板上所有卡片的專案名（master 卡為「Master」）。
- 標籤選項：看板的標籤清單，另加「無標籤」。
- Master 卡：自己符合（專案選「Master」或自己的標籤符合），或底下任一張卡符合，就顯示。
  自己符合時底下卡全部列出；只因底下卡符合而顯示時，只列出符合的卡。
- 欄位標題的數字是篩選後的數量。
- 有篩選作用時，頂列出現「清除篩選」。
- 篩選條件存在瀏覽器（localStorage `vibeflow:board-filters`），重整後保留。
  已勾選但已消失的專案仍列在選單中可取消；已刪除的標籤自動忽略。
- Done 卡不會有標籤（`writeBoard` 規則），所以勾任何標籤時 Done 欄只剩符合「無標籤」或因底下卡符合而顯示的 master。

## 假設（未逐條與使用者確認）

1. 由單選改為複選，取代原本的 ProjectFilter。
2. 篩選條件跨重整保留（與 Issues & PRs 篩選一致）。
3. 加入「無標籤」選項。

## 不包含

- 工作區（workspace）頁的卡片列表不套用此篩選。
- 不改 core、store 或 handler table。
