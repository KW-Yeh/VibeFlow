# Spec：npm 更新提示與版本顯示

- 狀態：已實作
- 需求來源：使用者要求 VibeFlow 執行時每兩小時檢查 npm 新版，並在設定視窗顯示目前版本。

## 目標

讓使用 npm 發佈版的使用者在開著 VibeFlow 時得知新版本已發布，並能在設定中確認目前執行的 host 版本。檢查只提示更新，不自行安裝或重新啟動。

## 行為

- Host 啟動時查一次目前套件的 npm `latest` dist-tag，此後每兩小時查一次；所有 Web UI 共用查詢結果。
- 只有 `latest` 高於執行中的版本時顯示更新提示，並附 `vibeflow update` 與重新啟動說明。
- 開啟較晚的 Web UI 也能讀取已查到的更新資訊。使用者可關閉提示；若查到更高版本，提示再次出現。
- 設定視窗顯示執行中的 host 版本，不以 renderer 的建置版本代替。
- 原始碼執行不查 npm：原始碼套件名稱不是發佈名稱，且 `vibeflow update` 不適用。
- npm 無法連線時不顯示錯誤提示；已成功取得的版本資訊保留到下次成功查詢。

## 驗收

- 版本比較只將較高的 npm 版本判定為更新。
- 檢查間隔為兩小時，失敗不影響 host 啟動或運作。
- Web UI 能顯示、關閉更新提示，並在收到更高版本事件後再次顯示。
- 設定視窗顯示 `app:getVersion` 回傳的版本。
